# 参考资料获取方式

本仓库**不包含**任何第三方源码。开发时用到的参考材料按需拉取到 `reference/`，
该目录已被 `.gitignore` 排除。

## 1. 官方 DeepSeek Harness 源码（权威依据）

UI 与插件 API 的权威来源。MIT 协议，公开仓库，默认分支 `master`：

```sh
# 用加速节点克隆（国内直连常失败，见 docs/GitHub加速约定.md）
git clone --depth 1 --branch dsh-v0.2.0-rc.2 `
  https://gh-proxy.com/https://github.com/deepseek-ai/deepseek-harness.git `
  reference/deepseek-harness
```

按**实际安装版本**取 tag，不要照抄 `master`。关键目录：

| 路径 | 内容 |
|------|------|
| `packages/client/ui-primitives/src/` | 官方控件库（Button / Switch / Input / Tag / Modal / MarkdownText …） |
| `packages/client/ui-primitives/README.zh.md` | 组件目录与「不要复制控件」的规则 |
| `packages/client/ui-plugin-manager/src/client/PluginManagerPage.module.css` | 「插件」页的权威样式（本插件页面的几何来源） |
| `packages/client/ui-schedule/src/` | 另一张列表页范式 |
| `packages/client/ui-theme/` | `--dsw-*` token 全表 |

也可以用 GitHub API 按需读取单个文件，不必整仓克隆。

## 2. 已安装版本的编译产物（核对 nightly 差异）

`app.asar` 未加密、未编译成字节码，成员逐字存储，可直接按字节提取：

```sh
node tools/asar-extract.mjs `
  "D:\Soft\Other\DeepSeek Harness\resources\app.asar" `
  reference/installed `
  "dsh/node_modules/@deepseek-ai/dsh-client-ui-plugin-manager"
```

**为什么要两份**：安装走 nightly 通道，GitHub tag 上的源码可能与实际运行的版本不同。
照抄样式前先比对，避免按旧版本实现。

## 3. 社区插件家族（可选参考）

`github.com/zhu1090093659/dsh-web`（BSD-3-Clause）。它含一个「技能中心」实现
（`packages/dsh-skill-explorer`），但**只管本地技能、不能安装网络技能**，且页面样式
是手写的而非官方 primitives。可作为行为参考，**不要照抄其 UI**。

```sh
git clone --depth 1 --branch dev `
  https://gh-proxy.com/https://github.com/zhu1090093659/dsh-web.git `
  reference/dsh-web
```

注意该仓库默认分支是 `dev` 而不是 `main`。

## 为什么这些不进仓库

- 体积：三个来源合计约 660 MB，会把 history 撑爆。
- 授权：官方应用代码与第三方仓库各有其许可，本包无权再分发。
- 时效：参考材料是**快照**，随上游变动而失效；权威来源始终是上游。
